Spring Boot + htmx サンプル

キーボードショートカット

画面上のボタンと Alt+Shift+D のどちらからも、同じ GET 要求で案内パネルを取得します。

  1. ボタンを押し、説明用パネルだけが入れ替わることを確認します。
  2. 入力欄の外にフォーカスを移し、Alt+Shift+D を押して同じ操作を行います。
  3. 入力欄・編集可能領域にフォーカスして同じキーを押し、ショートカットが発火しないことを確認します。
  4. 開発者ツールで要求を遮断し、失敗通知が出て現在のパネルが残ることを確認します。

操作を試す

案内を取得しています…

ここにフォーカスがある間は Alt+Shift+D を押しても要求しません。入力内容は送信しません。

取得結果

案内を取得しました。これは参照 GET で、サーバー状態は変更していません。

ボタンまたは Alt+Shift+D で、サーバーから案内を取得できます。

仕組みと通信

ショートカットとボタンは同じフォーム送信を行います
操作メソッド / URL応答・差し替え
初期表示GET /examples/keyboard-shortcuts200・ページ全体と初期案内
ボタン・Alt+Shift+DGET /examples/keyboard-shortcuts/action200・htmx は結果パネルだけを差し替え。通常送信は結果入りの全体ページ
HTTP エラー・通信断・タイムアウト同上エラーを通知し、現在のパネルを保持
  • フォームは標準 GET 送信を持ち、JavaScript が有効なら htmx が応答を結果パネルに差し替えます。無効時は結果を含むページを開きます。
  • 外部 JavaScript は Alt+Shift+D を検出すると同じフォームを送信します。htmx の条件式やインラインイベント属性は使いません。
  • 入力欄・編集可能領域・開いたダイアログ内、キー入力の変換中、修飾キーの組み合わせ違いではショートカットを無視します。
  • 通信中表示、二重取得の抑止、エラー通知は共通 JavaScript と htmx 属性で行います。失敗時は応答断片を差し替えません。

状態・制約

固定の案内だけを使います。要求は状態を変更しない GET で、DB・セッション保存・外部 API・追加依存はありません。ショートカットはこのページ内だけで動作します。

公式例との差分・出典

htmx 公式 Keyboard Shortcuts のグローバルキー操作とボタンの併用を参考にしています。公式例の POST と hx-trigger 内の条件式は採用せず、状態を変更しない GET と外部 JavaScript のキー判定に置き換えています。入力中の誤発火防止、通常フォーム代替、通信失敗時の通知を追加しています。
