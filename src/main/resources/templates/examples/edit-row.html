行を編集

一覧の行だけを編集フォームに切り替え、保存またはキャンセルでその行だけを表示へ戻します。

  1. 任意の行で「編集する」を押し、名前とメールを変更します。複数行を独立して編集できます。
  2. 「保存する」で行を更新、「キャンセル」で未保存の入力を捨てて最新の保存済み内容に戻します。
  3. 名前を空欄にして保存すると、入力を残したままその行にエラーが出ます。

仕組みと通信

各行の hx-target="this" と hx-swap="outerHTML" で、応答の一行を置き換えます。別の行の入力内容はそのまま残ります。

URL は /examples/edit-row 配下。htmx の対象は #person-row-{id}
操作メソッド / URL応答
一覧GET /examples/edit-row200・ページ全体
編集GET /{id}/edit200・編集用の tr
保存POST /{id}200・表示用の tr。不正入力は422・入力とエラーを含む tr
キャンセルGET /{id}200・最新の保存済み tr。GET は状態を変更しない
初期化POST /reset一覧の版を照合し、全体ページへリダイレクト

通常アクセスは一覧全体を返し、通常フォームの保存成功時は一覧へリダイレクトします。不正入力は422で編集行を含む全体ページです。htmx の保存・キャンセルは他の編集行を変更しません。

  • hx-sync="this:drop" は同じ行の通信中に重複要求を捨てます。hx-disabled-elt="find button" で行内の保存・キャンセル等を一緒に無効にします。異なる行は並行操作できます。
  • HTML の制約に合わせ、form は操作セル内に置き、名前・メールは form 属性で関連付けます。htmx も通常フォームもこの入力を送信します。
  • GET 操作には hx-params="none" を指定して不要な値を URL に含めません。更新時は通常フォームの hidden 項目、htmx は追加のヘッダーでも CSRF トークンを送ります。
  • EditRowController は入力と表示の選択、EditRowState は3行と版の管理を担当します。ContactForm の名前・メール・版の検証を「クリックで編集」から再利用します。app.js は422差し替え、通知、フォーカスを扱います。

異常系と操作性

  • 名前は必須・60文字以内、メールは必須・形式検証・254文字以内（Java の文字列長）。422後は最初の不正入力へフォーカスを移します。編集開始は名前、保存・キャンセル後は編集ボタンへ戻ります。
  • 同じ行を別タブで開き、一方で保存後にもう一方で保存すると409です。入力は差し替えず残すので、必要なら控えてキャンセルまたは再読み込みしてください。別の行の保存は競合しません。
  • 古い行の版は入力エラーより先に409です。版が空欄・36文字超過等の制約違反なら422、制約内でも現在の版と不一致なら409です。
  • 存在しない ID は404、数値でない ID は400。CSRF 欠落・不一致は403。成功に偽装せず通知し、htmx では入力を残します。
  • 通信断・10秒のタイムアウトでは通知し、保存済みと決めつけません。入力を控えて状態を再取得してください。

状態の寿命と制約

一覧はセッションごとの3件だけで、追加・削除はありません。同じセッションのタブは共有し、別セッションとは分離します。無通信20分・サーバー再起動で消えます。初期化は行の版も更新し、古い編集からの保存を拒否します。

DB・外部 API・追加依存なしのローカル学習用です。サーバー全体で100セッション、フォーム16KB・パラメーター20個を上限とし、超過は503・413・400で通知します。認証・認可を備えた本番向け連絡先管理ではありません。

公式例との差分・出典

htmx 公式 Edit Row の行単位の表示・編集切り替えを参考に独自実装しています。公式例の単一行編集・SweetAlert・インライン JavaScript は使わず、複数行の独立編集と標準フォームを採用しました。

公式例の PUT と hx-include の代わりに POST と form 属性を使い、JavaScript 無効時にも操作できるようにしています。CSRF、422、版照合、初期化、日本語説明とフォーカス復帰を加えました。
