タブ（HATEOAS）

どのタブを表示するかは URL で表し、サーバーが選択中のタブとタブ一覧を HTML で返します。

  1. タブを選び、URL・選択表示・内容が一緒に変わることを確認します。
  2. ブラウザーの戻る・進むで選択状態が URL に応じて復元されることを確認します。
  3. キーボードでは Tab でタブ一覧に入り、左右矢印で移動、Enter または Space で選択します。Home / End は先頭・末尾へ移動します。

仕組みと通信

サーバーが URL に対応するタブ一覧と選択中の内容を返します
操作メソッド / URL応答・画面更新
初期表示GET /examples/tabs-hateoas200・ページ全体。概要を選択状態にする
タブ選択GET /examples/tabs-hateoas/tab/{tabId}200・htmx 要求ではタブ一覧と内容の断片を差し替え、URL 履歴も更新。通常要求ではページ全体
戻る・進むGET /examples/tabs-hateoas/tab/{tabId}履歴復元要求ではページ全体を返し、htmx が現在の履歴 URL の状態を復元
存在しないタブ IDGET /examples/tabs-hateoas/tab/{tabId}404。既存の表示を維持してエラーを通知
通信失敗・タイムアウト同上現在のタブを維持して通知。タブリンクから再試行可能
  • 各タブは通常のリンクであり、JavaScript が無効でもページ全体を取得できます。htmx は同じリンクを GET し、返された選択状態と内容をまとめて差し替えます。
  • 選択状態はサーバーがリクエスト URL から決めます。JavaScript はタブ内のフォーカス移動だけを補助し、選択状態を別に持ちません。
  • hx-push-url で選択した URL を履歴に追加します。履歴復元時は htmx の復元要求を判別し、全ページを返します。Vary で応答形式のキャッシュ混同を防ぎます。
  • GET は固定の架空説明を参照するだけです。DB・外部 API・セッション状態・追加ライブラリは使いません。

キーボードとアクセシビリティ

タブ一覧は左右矢印でフォーカスを移動する手動選択方式です。Enter / Space で選択するとサーバー応答を反映します。選択状態・タブパネルとの関連は、応答 HTML の aria-selected、aria-controls、aria-labelledby で表します。

公式例との差分・出典

htmx 公式 Tabs (Using HATEOAS) のように、サーバーが選択中のタブ一覧と内容を含む HTML を返します。この例では通常リンクによる全ページ表示、URL 履歴、キーボード操作、エラー通知を加えています。JavaScript による選択状態の管理は行いません。
