HTTP エラー・通信断・タイムアウトGET /examples/dialogs-custom/detail成功として扱わず、共通通知を表示。ダイアログは開かない
  • showModal() がモーダル表示、背後の操作抑止、ダイアログ内へのフォーカス移動を提供します。外部 JavaScript は成功した差し替え後に開き、Escape キーを明示的に閉じる操作へつなぎます。
  • form method="dialog" は送信リクエストを作らずに閉じる標準 HTML の仕組みです。close イベントでは、外部 JavaScript が要求時に記録した起動要素へフォーカスを戻します。
  • htmx の応答は `HX-Request` に応じて断片または全ページを返し、Vary: HX-Request でキャッシュの混同を防ぎます。ヘッダー値は認可・検証の省略条件にしません。
  • 取得内容は固定の架空案内です。GET は参照のみで、状態の変更・保存はありません。失敗時に自動再試行は行わず、起動ボタンから再試行できます。

異常系と制約

取得失敗・タイムアウトでは既存ページを維持して共通通知を表示します。ダイアログは正常な差し替えが完了するまで開きません。ネイティブのダイアログ表示・フォーカス挙動はブラウザーに依存します。

公式例との差分・出典

htmx 公式 Dialogs - Custom は独自オーバーレイと Hyperscript を使います。この例では依存追加と独自のフォーカス管理を避けるため、標準 <dialog> のモーダル・Escape・フォーカス動作を使い、外部 JavaScript から htmx の差し替え後に開きます。閉じるボタン、通常ページ代替、エラー通知、日本語解説を加えています。
