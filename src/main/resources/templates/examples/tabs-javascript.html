  • 通常のリンクに hx-get を加えます。JavaScript が無効ならブラウザーがページ全体を開き、htmx が有効なら内容だけを取得します。
  • サーバーは初期表示と通常ページで内容を選びます。部分応答には内容だけを返し、外部 JavaScript が成功後に aria-selected、tabindex、パネルの関連付けを更新します。
  • htmx による選択は URL やサーバー状態に保存されません。URL履歴・DB・セッション・外部 API は使わず、ベース URL を再読み込みすると概要に戻ります。通常リンクで開いたタブ別 URL はその内容を表示します。
  • 全通信は固定データを参照する GET です。htmx の条件式やインラインイベント属性を使わず、安全設定 allowEval: false を維持します。

キーボードとアクセシビリティ

左右矢印と Home / End はフォーカスだけを移動する手動選択方式です。Enter / Space で取得を開始し、成功応答後に選択状態を更新します。選択状態・タブパネルとの関係は aria-selected、aria-controls、aria-labelledby で示します。

No.20 との違い・公式例との差分

htmx 公式 Tabs (Using JavaScript) と同様に、選択された内容だけを取得して選択表示をクライアントで切り替えます。No.20 はサーバーが選択中の一覧と内容を返して URL 履歴にも状態を反映しますが、この例では外部 JavaScript が成功後に選択表示を更新し URL 履歴は変更しません。公式例のインライン hx-on と let 式は、CSP と allowEval: false を維持するため外部 JavaScript のイベント処理に置き換えています。通常リンクの全ページ代替、キーボード操作、エラー通知も追加しています。追加依存はありません。
