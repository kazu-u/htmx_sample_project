## 状態・安全性・未確認事項

- htmx の選択状態はブラウザー内だけで管理し、URL履歴・サーバー・セッションには保存しません。ベース URL の再読み込みでは概要に戻り、通常リンクで直接開いたタブ別 URL ではサーバーがその内容の全ページを返します。
- すべて固定の架空説明を返す GET で、更新・CSRF を要する操作・DB・外部 API はありません。タブ ID は固定一覧から検索し、存在しない ID は404です。出力には Thymeleaf のエスケープを使います。
- `hx-on` とインライン JavaScript を使わず、htmx の `allowEval: false` と CSP を維持します。追加依存はありません。
- **未確認:** 素早い連続選択・要求中断時の実ブラウザー挙動、実ネットワークの遅延・切断・タイムアウト、別ブラウザー、スクリーンリーダー、OS のハイコントラスト設定。

## 公式例との差分

[htmx 公式 Tabs (Using JavaScript)](https://htmx.org/examples/tabs-javascript/) と同様に、選択された内容だけを htmx で取得し、クライアント側で選択表示を切り替えます。公式例のインライン `hx-on` と `let` 式は、CSP と `allowEval: false` を維持するため外部 JavaScript のイベント処理に置き換えました。通常リンクによる全ページ表示、キーボード操作、エラー通知、失敗時の表示保持を追加し、URL履歴は変更しません。
