## 実ブラウザー確認

環境: VS Code 統合ブラウザー（Chromium 系、正確なブラウザー・エンジンの版は確認手段から取得できず）。サーバーは `.\mvnw.cmd spring-boot:run` で起動し、`http://127.0.0.1:8080/examples/value-select` を使用。

| 操作 | 結果 |
| --- | --- |
| 初期表示 | 親は未選択、子は未選択かつ無効。画面解説と通信表が表示される |
| 親を選択 | htmx GET で対応する候補に置換。親欄のフォーカスを保持 |
| 子を選択して確認 | 選択結果だけを置換し、結果を表示 |
| 親を変更・解除 | 変更時に子の選択と以前の結果をクリア。親解除時は子候補がなくなり、子欄が無効 |
| 不正な子 ID を送信 | 422 の応答を画面へ差し替え。親を保持し、子を未選択へ戻し、エラーを読み上げ用状態へ表示して子欄にフォーカス |
| 親未選択で確認 | 送信ボタンを伴わない htmx フォーム送信も結果確認として処理。422 の具体的なエラーを表示し、親欄を `aria-invalid="true"` にして親セレクトへフォーカス。ページ全体や重複領域は挿入されない |
| 親エラーからの復帰 | 有効な親を選ぶと親のエラー表示・無効状態を解除。フォーカスを保持したまま子候補を取得 |
| JavaScript を読み込まない状態 | スクリプトをブラウザーで遮断し、通常フォームで候補取得・選択確認。どちらもページ全体の応答で成功 |
| 通信断 | 候補取得をブラウザーで中断し、通信エラーを通知。親の選択は保持 |
| キーボード・狭い幅 | Tab で親セレクトへ到達し、キー操作で親を選択できる。幅390pxで本文の横スクロールなし（本文幅375px） |

通信断の試験では、直前の市区町村候補を表示したままにし、エラーを通知しました。次の正常な親候補取得で置き換わります。別の親の子 ID が確認要求に送られても、サーバーが親子関係を再検証して422にします。
