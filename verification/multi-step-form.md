# C03 複数ステップフォームの検証記録

## 対象

- 要件: F-35
- 仕様: 架空の出張申請を申請者・出張内容・確認の3段階で入力する。段階別の検証、戻る・次へ、セッション内下書き、完了・リセット、CSRF、古い画面の409を扱う。
- 実施日: 2026-11-03

## サーバーテスト

| コマンド | 結果 |
| --- | --- |
| `.\mvnw.cmd --batch-mode -Dtest=MultiStepFormTests test` | 成功。9テスト、失敗・エラーなし |
| `.\mvnw.cmd --batch-mode verify` | 成功。269テスト、失敗・エラーなし。パッケージ検証も成功 |

テストでは、各段階の入力検証、文字数境界、日付範囲、入力保持、戻る操作、確認・完了、二重確定の拒否、リセット、通常フォームのリダイレクト、CSRF、セッション分離、段階飛ばし・古いrevisionの409、Thymeleafのエスケープを確認した。

## ブラウザー確認

統合ブラウザーで `http://127.0.0.1:8080/examples/multi-step-form` を操作した。

- 申請者から出張内容、確認、完了へ進み、htmx が `#application-wizard` のみを差し替えることを確認。
- 終了日を開始日より前にして送信し、422の項目エラー表示、入力保持、エラー項目へのフォーカス、読み上げ用ステータスを確認。
- 日付を修正した後、確認画面に値が表示され、「確認画面を表示しました。」の通知が出ることを確認。
- 確認から出張内容へ戻り、値が保持されることを確認。
- 出張内容から申請者へ戻る操作、明示リセットによる初期化、完了画面への遷移を確認。
- ブラウザーで入力した架空データは、検証後にリセットして消去した。

## 未確認事項

- JavaScript を無効にした実ブラウザー操作。通常フォーム経路は MockMvc のサーバーテストで確認した。
- 実際の20分経過によるセッション失効、ネットワーク切断・タイムアウト、別ブラウザー、スクリーンリーダー、モバイル幅。
- ブラウザー履歴による段階移動は仕様対象外。段階は画面内の戻る・次へで移動する。

## 環境

- テスト・アプリ実行 JDK: Java 25.0.2
- ブラウザー: 統合ブラウザー。製品名・バージョンは取得できていない。
