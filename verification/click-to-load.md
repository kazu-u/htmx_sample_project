# Click To Load の検証記録

- Windows / Eclipse Temurin Java 25.0.2
- Spring Boot 4.1.2 / htmx 2.0.11 / Maven Wrapper 3.9.16
- 実ブラウザー: VS Code 統合ブラウザー。ブラウザー製品・バージョンは取得できず

| `.\mvnw.cmd --batch-mode -Dtest=ClickToLoadTests test` | 成功。5件、失敗・エラー・スキップなし |
| `.\mvnw.cmd --batch-mode verify` | 成功。全36件、失敗・エラー・スキップなし |

ページ全体と htmx 断片、3ページ目の終端、通常 GET の累積表示、ページ番号の範囲外・数値以外を確認しました。

## ブラウザー確認

- 初期表示は担当者3件と読み込み操作を表示。
- htmx で2ページ目を読み込むと6件になり、次の操作が残る。3ページ目では8件になり操作がなくなる。
- htmx の次ページ応答をテスト用に404へ置き換え、エラー通知が表示されて一覧の既存行が維持されることを確認。
- htmx ファイルをテスト時に空応答へ置き換え、通常フォームで `?page=2` に遷移し、最初の6件と次の操作がページ全体に表示されることを確認。
