## 状態・安全性・未確認事項

- 選択状態は URL の固定タブ ID からサーバーが導きます。JavaScript はキーボード操作とフォーカス移動だけを補助し、選択状態を独自に保持しません。
- すべて GET の固定架空コンテンツで、セッション・DB・外部 API に状態を保存しません。タブ ID は固定一覧から検索し、存在しない ID は 404 で拒否します。
- **未確認:** JavaScript 無効化状態の実ブラウザー操作。通常の GET で各タブを全ページ表示できることはサーバーテストと直接アクセスで確認しました。
- **未確認:** 別ブラウザー、実ネットワークの遅延・切断、実際のサーバー障害。
- **未確認:** スクリーンリーダーによる読み上げと OS のハイコントラスト設定。

## 公式例との差分

[htmx 公式 Tabs (Using HATEOAS)](https://htmx.org/examples/tabs-hateoas/) と同様に、選択状態を含むタブ一覧と内容をサーバーが返します。この例では URL 履歴、通常リンクによる全ページ表示、手動選択式のキーボード操作、404・通信エラー通知を加えています。追加依存はありません。
