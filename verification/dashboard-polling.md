## ブラウザー確認

- `/examples/dashboard` を開き、注文・在庫カードの値とサーバー取得時刻が5秒ごとの GET で更新されることを確認した。
- 注文カードの手動更新で注文だけが更新され、在庫カードの取得時刻は変化しないことを確認した。
- 注文カードの要求に HTTP 503 を返すと、値・取得時刻が保持され、カード別の古い情報表示と共通エラー通知が表示され、自動取得が停止した。503 を解除して手動更新すると最新値が表示され、古い情報表示が消え、自動取得が再開可能になった。
- 自動更新を一時停止して6秒待ち、取得時刻が変化しないことを確認した。再開時は正常な2カードを直ちに個別取得した。
- ブラウザーのタイマーを5分1ミリ秒進め、自動更新の上限表示、停止状態、制御ボタンの無効化を確認した。
- 両カードへHTTP 503を返して各カードの自動取得を止めた状態でも、表示時間を累計5分まで進めると全体の上限表示と停止状態へ移ることを確認した。
- 単調増加時計で上限を計ることを確認するため、表示時間を1分進めた後に端末時刻を10分戻して一時停止・再開し、残り4分を進めると累計5分で自動更新が停止した。
- 別ページを開いてダッシュボードを非表示にすると、6秒間カード要求が0件であることを確認した。ダッシュボードに戻ると2カードが再取得された。
- 通常 GET `/examples/dashboard/summary/orders` は両カードを含むページ全体を返した。
- 意図的に模擬した HTTP 503 はブラウザーのコンソールに記録された。予期しない JavaScript 実行時エラーは確認されなかった。
