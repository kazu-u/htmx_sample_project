# Animations 検証記録

## 対象

- 要件: F-01、F-04、F-06〜F-09、F-21
- 検証日: 2026-10-31
- 対象: 固定のカード表示を htmx GET で切り替え、安定した ID と CSS transition で差し替えを表現する。

## サーバー側検証

環境: Windows、Java 25.0.2、Maven Wrapper 3.9.16。

| コマンド | 結果 |
| --- | --- |
| `.\mvnw.cmd --batch-mode clean verify` | 成功。全159テスト、失敗・エラー・スキップなし |
| `git diff --check` | 成功。空白エラーなし |

## 実ブラウザー確認

環境: VS Code 統合ブラウザー（Chromium 系、正確なブラウザー・エンジンの版は確認手段から取得できず）。サーバーは `.\mvnw.cmd spring-boot:run` で起動し、`http://127.0.0.1:8080/examples/animations` を使用。

| 操作 | 結果 |
| --- | --- |
| 初期表示 | 3つの選択ボタンと初期カードを表示。htmx とサンプル CSS を読み込む |
| htmx でカードを変更 | GET で HTML 断片を受け取り、ページ全体は置換せず、同じ `animation-card` ID を維持して色・文を変更 |
| swap / settle と CSS | htmx の `htmx-swapping`、`htmx-added`、`htmx-settling` が差し替え過程で付くことを確認。新しいカードは opacity が0から1へ240msでフェードインし、色・背景色は新要素へすぐ適用 |
| 処理中・フォーカス | 要求中に全選択ボタンを無効化し、インジケーターと busy 状態を表示。応答後は操作元ボタンにフォーカスを戻し、完了を通知 |
| 動きを減らす設定 | `prefers-reduced-motion: reduce` をブラウザーで模擬し、カード transition が `0.00001s` に短縮されることを確認 |
| 不正な ID | ID なしは400、存在しないIDは404。404を共通エラー通知で示し、現在のカードを維持。ボタンを再び有効にし、操作元へフォーカスを復帰 |
| JavaScript 無効 | スクリプトをブラウザーで遮断し、通常 GET フォームで選択したカードを含むページ全体を表示 |
| 狭い画面 | 幅390pxで本文の横スクロールなし（本文幅375px） |

## 制約・未確認事項

- 表示候補は架空の固定値3件。状態保存、データベース、外部 API、View Transitions API、htmx 拡張、追加依存はありません。
- Firefox 等、統合ブラウザー以外のブラウザー、画面読み上げソフト、モバイル実機は未確認です。
- 実機 OS の「動きを減らす」設定ではなく、ブラウザーの reduced-motion 設定を模擬しました。
- 意図的なサーバー遅延を用いた長時間の処理中確認、タイムアウト待機、CSP 違反の記録は未確認です。
- 404 に伴うブラウザーの HTTP エラーログは想定した応答です。JavaScript の実行例外がないことを独立監査したものではありません。
